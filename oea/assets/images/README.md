# État des visuels

**Logo officiel (intégré) :**
- `logo-oea-mark-dark.png` — version "négative" (blanc sur transparent), utilisée dans le header et le footer de chaque page sur le fond sombre du site.
- `logo-oea-mark-original.png` — version couleurs d'origine (noir sur transparent), utilisée en grand format dans la section "Signification & symbolique" de `a-propos.html`.

Les deux sont générées à partir de ton fichier logo haute résolution, recadrées au plus près et avec un fond rendu transparent — aucune image bitmap "brute" n'est utilisée telle quelle.
